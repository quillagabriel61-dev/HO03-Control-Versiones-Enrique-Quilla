# Control de Versiones para Proyecto de Software

## Descripción del caso práctico
Una empresa de desarrollo de software necesita organizar los archivos de sus proyectos y mantener un historial de los cambios realizados para identificar modificaciones y recuperar versiones anteriores.

## Objetivo del repositorio
Implementar un repositorio en GitHub que permita organizar los archivos de un proyecto, registrar los cambios de forma estructurada y demostrar el uso de ramas para trabajar de manera ordenada.
